# 声・字幕・モーション（2026-09-09）

## Google Vidsの声と人物

ナレーションパネルで声（30種類）、人物（リアル・3D・2D）、読み方、笑い・ため息等、自由記述の演技指示を指定します。「原稿と引き渡しファイルを作る」でプロジェクト内に設定と台本を保存します。原稿コピーには `[whispers]` / `[laughs]` 等の音声タグを含みます。タグ込み2500文字までです。

Vidsを開き、指定した声または人物を選んで台本を貼り付けて生成してください。人物アバターには固有の声があり、声のみの選択で上書きできません。自由記述の演技指示は、Vidsの「音声タグを適用」やタグメニューを使って反映します。音声やMP4をCuttonへ戻すと、映像とは別の音声素材になります。

これは設定・台本の引き渡しと生成物の取り込みです。Cutton単体でVidsを無人操作する機能ではありません。利用プラン・言語・アカウントで声や人物が変わる場合があります。選択肢は2026-09-09の実際のVids画面で確認した内容です。Vidsでの試聴が必要です。

## 字幕

字幕パネルにフォント・太さ・サイズ・文字色・縁取り幅と色・不透明度・字間・行間・影・グラデーション角度・背景ボックスを追加しました。メイリオ、游ゴシック、游明朝、Arialを使用します。OSにないフォントや未収録の文字は代替表示され、ブラウザと書き出しの字形に差が出る場合があります。

カラオケは「文字をなぞる」「単語ごと」の2方式です。未指定時は尺に均等配分し、読み上げタイミングで調整します。自動音声認識・自動歌詞アラインメントは未実装です。CLIの `words` には `{text,start,end}` の配列を指定できます。時刻は字幕の開始からの相対秒、各区間は重複不可、文章の連結は字幕全体と一致させます。

タイプライター、一文字ずつのフェード・上昇・ポップ、波打ちに対応。プレビューとMP4は共通のSVG・タイミング計算を使います。SRTには文字と時刻のみを出力し、装飾やカラオケはMP4への焼き込み、またはCuttonのプロジェクト保存で保持します。

## モーション

多角形・星形、頂点数・内径、塗りの透明度、線の描画・消去と範囲、グラデーション角度、最大20個の反復と位置・回転・透明度を追加しました。登場・弾み・浮遊・周回・回転・拡縮を編集可能なキーフレームへ展開できます。登場と回転は1回、浮遊・周回・拡縮は最大8回です。既存のベジェ曲線・親子・マスク・マット・グローと組み合わせます。

`node examples/creative-demo.mjs` で、現在のプロジェクトを変更せず、`output/creative-demo` に3秒のMP4と編集可能なプロジェクトを作成します。音声なしの字幕・図形デモです。

## このPCの設定

Core Ultra 7 155H（16コア・22スレッド）、実メモリ約15.4GiB、Intel Arc内蔵GPUを確認しました。CPU/RAMから書き出し4スレッド・プレビュー2スレッド・合成2スレッドを選び、4Kではエンコードを最大2スレッドに抑えます。書き出しジョブは1本ずつ処理します。GPUの専用VRAM容量はWindowsの表示値から推定しません。

プロジェクト解像度・fps・元素材の参照を維持し、プレビュー用プロキシを完成動画へ流用しません。合成の中間H.264をCRF 0、完成MP4を従来どおりCRF 18にしました。最終MP4は非可逆のSDR/8bitです。中間ファイルは大きくなるため空きディスクが必要で、レンダー後に作業用ファイルを削除します。元の素材ファイルは変更しません。

字幕の文字分割・配置・時刻表をキャッシュし、動画フレームはため込まず逐次処理します。大規模案件のリアルタイム再生やAE全機能との品質一致を保証するものではありません。
