# Cuttonの起動

デスクトップの「Cutton」を開くか、[公開UI](https://kentasasayuri.github.io/Cutton/)の「Cuttonを起動」を押します。編集エンジンが停止していれば起動し、準備を確認した後に既定のブラウザでプロジェクト選択画面を開きます。起動済みなら同じエンジンを再利用します。

公開UIの閲覧とローカル編集にOpenAIアカウントは不要です。Codex App ServerやGPT Imageを使う操作だけは、PC側でCodexへのログインが必要です。

## 公開UIとローカルエンジン

公開UIはGitHub Pagesから静的ファイルとして配信されます。素材、プロジェクト、書き出しファイルはPC内に残り、GitHubへ送信されません。

初期表示ではPCへ自動接続せず、起動操作を表示します。「別の開き方 → この画面で接続する」を選んだ場合だけ、ブラウザから `127.0.0.1:4318` の編集エンジンへ接続します。初回はブラウザのローカルネットワーク接続許可が必要になる場合があります。

ローカルエンジンは、設定されたGitHub Pagesオリジンからの接続だけを受け付けます。接続時に一時トークンを発行し、API、素材、ダウンロードへの未認証アクセスを拒否します。許可する公開UIを変更する場合は `CUTTON_UI_ORIGIN` を設定します。

## PCの起動登録

`scripts/install-launcher.ps1` は、このWindowsユーザー専用の `cutton://` とデスクトップショートカットを登録します。起動先はチェックアウト内の `scripts/launch.vbs` に固定され、URLから任意のコマンド、ファイル、プロジェクトを指定することはできません。

起動時はポートごとの排他処理で二重起動を抑え、Cuttonのヘルス応答を確認してから画面を開きます。他のアプリが同じポートを使用している場合は終了や乗っ取りを行いません。起動失敗の詳細は `output/server-error.log` に保存されます。

Webブラウザによっては、初回に外部アプリを開く確認が出ます。独自URLを扱えない場合はデスクトップショートカットを使用してください。この登録はPCごとに必要です。
