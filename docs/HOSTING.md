# Cuttonを無料枠のクラウドで動かせるか

2026-09-09に公式条件を確認。AWSリソースの作成・契約・課金設定は行っていません。

| 構成 | 適性と条件 |
|---|---|
| 現在のPCでUIと編集エンジン | 元素材・CodexログインをPCに保持。現状で機能がそろう構成。電気代・PC稼働は必要 |
| SitesのUI＋PCの編集エンジン | UIを配信可能。ただしブラウザのローカルネットワーク制約で接続できない場合は「このPCでCuttonを開く」でローカルUIへ移動 |
| AWS EC2でUI＋FFmpeg | 移植可能だが、認証・TLS・ストレージ・バックアップ・アップロード・フォント・費用管理が必要。現在のlocalhost専用エンジンをそのままインターネットへ公開しない |
| AWSでComfyUIも生成 | モデルに応じたGPUと保存容量が必要。EC2無料対象の小型CPUインスタンスで同じ生成性能を維持できるとはいえない |

2025-07-15以降に作成したAWSアカウントは、開始時100ドル＋条件達成で追加最大100ドルのクレジット制で、無料プランは6か月またはクレジット消費までです。永続無料の動画編集サーバーではありません。それ以前のアカウントは12か月の従来枠が適用される場合があります。

小さなEC2でもCPUレンダーの解像度や設定を維持すること自体はできますが、速度・RAM・保存容量の制約があります。無料対象のCPUインスタンスはGPU生成の代替になりません。Codex App Serverはログインした実行環境が必要で、ChatGPTサブスクリプションはAWSの計算資源費用を支払いません。Google Vidsも別途対象プランで利用します。

現時点では、このPCで編集処理を続け、必要になったときにレンダリングだけクラウドへ送る設計が現実的です。そのクラウドキュー・認証・転送は未実装です。サーバーに移す場合は日本語フォントのライセンスと代替フォントも検証が必要です。
