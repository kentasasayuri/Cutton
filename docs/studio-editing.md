# Cutton 音声・複数選択・テロップ・背景の拡張

2026-09-12

## 操作

- 音声ミキサー →「音声の仕上げ」：トラックを指定して設定を調整し「調整音を作って適用」。タイムラインの「一括編集」からは選択中の音声だけ処理できる。
- ピッチ ±12半音、フォルマント保持、FFTノイズ低減、ノイズフロア、ゲートとリリース、歯擦音抑制、低域カット、声の厚み・明瞭感、圧縮比・しきい値・補正ゲイン、短いルーム反射、ディレイ、出力ゲイン。
- 試聴は保存済み音と原音を同じ使用範囲・速度で比較する。比較プレイヤーはミキサーやクリップのゲイン・フェードを通さない。通常再生ではそれらも適用する。
- ミキサーは使用中のトラックを初期表示。フェーダーは数値入力・矢印キー・ダブルクリックでの初期値復帰に対応。
- Ctrl / Cmd＋クリックで複数選択。「一括編集」で速度変更・複製・削除。速度は現在値への倍率。映像・音声に加え、選んだ字幕の単語時刻、モーションのキーフレーム、間隔も伸縮。最終素材速度は0.25〜4倍。
- 後続を移動する場合、範囲に重なる全要素の選択が必要。選択外の後続要素とマーカーも移動する。ストーリーボードの計画尺は変更しない。
- タイムラインにフォーカスすると矢印で1フレーム、Shiftで10フレーム、Alt＋矢印で選択要素の移動。Ctrl / Cmd＋Dで後ろへ複製、Shift＋Sで全映像・音声を分割。Mでマーカー、＋／−で拡縮、Fで全体表示（ズーム下限あり）。フォーム入力中は編集ショートカットを抑止。
- 字幕の「文字の質感」：8種類のスタイル、2重縁取り、3色グラデーション、光沢、光彩、擬似的な厚み。プレビューで確認して保存する。
- 背景：10プリセット、7種類の模様、3色の配色、角度・密度・濃さ・周辺減光。プロジェクト解像度で画像化し、既存背景を差し替えるか最下段へ追加する。

## 音声処理と品質

FFmpegを1クリップずつ、1スレッドのフィルターで実行。調整済み音声は48kHz / 24bit PCMの別素材として保存し、プレビューと書き出しで同じファイルを使う。元データのハッシュと範囲・設定から処理済み素材を再利用する。再調整は元音声から作り直すため、ピッチ変更やノイズ除去を累積しない。元音声は調整音が参照する限りライブラリからの削除を防止する。変更は1回の取り消しで戻せる。

処理対象は音声トラック。映像に音が含まれる場合は、その音声を音声トラックへ配置する。処理後は使用範囲だけの音声素材になるため、外側へトリムを延長するときは元音声を再配置する。反射音の末尾は現在の尺で切る。1回最大64クリップ・合計2時間。ノイズ低減の強さを上げると声の質感にも影響するため、原音比較で調節できる。

PitchはRubber Bandで音程と尺を分離。ノイズ除去は指定したノイズフロアを使い、意図せず設定を上書きする自動追従は無効。リミッターは遅延を補正し自動増幅をしない。音声ミキサーのリアルタイムコンプレッサーはWeb Audio方式で、書き出しのFFmpeg方式とは差がある。ルームは短い反射音を組み合わせた効果で、実空間のインパルス応答を使うリバーブではない。

## フォントと描画

既存5書体にDela Gothic One、DotGothic16、Klee One、Yusei Magic、Zen Kurenaido、Potta One、Rampart One、Train Oneを追加。Google Fontsの公式リポジトリからTTFとOFLライセンスを同梱した。紹介記事由来の一覧は元の35件を維持し、新規8書体は別の実装済み一覧として加える。各書体は必要なときだけ読み込む。追加8書体の実フォントはRegular（400）のみ。

字幕の質感はブラウザと書き出しが同じSVGを使う。立体表現は2Dの押し出し。背景は静止画像で、プレビュー中の模様生成負荷を避ける。元動画の解像度・書き出し品質の既定値は変更しない。

## 検証

合成PCMで440→880Hzと尺の保持、元ファイルの不変、再調整の440Hz復帰、キャッシュ再利用、ノイズエネルギー低減、各音声プリセットの実行を確認。複数選択の尺・単語・キーフレーム・マーカー・後続配置、失敗時の原子性、複製したグラフィックの親参照、取り消しを検証。10背景と8文字スタイルを実フォントでラスタライズ。処理済み音声のプロジェクト書き出し・再読み込みも検証する。
