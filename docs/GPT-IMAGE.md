# Cuttonの画像生成

「AI生成」→「GPT Image」で内容と比率を指定します。生成中も編集できます。完成したPNG/JPEG/WebPは、生成を開始したプロジェクトの素材へ追加されます。既存素材は上書きしません。

CLI / MCP: `image.generate {"prompt":"夕暮れの教室、柔らかい逆光","aspect":"16:9"}`。応答はジョブIDです。状態のjobsから完了・エラーを確認できます。最大4件待機、生成は1件ずつです。エンジン終了で中断したジョブは次回起動時に失敗として表示し、自動再課金・再生成はしません。

Codex App ServerのChatGPTログインと内蔵image_gen.imagegenを使用します。APIキーでは実行せず、API課金への自動切り替えもありません。利用枠はCodexと共有されます。アプリ専用のCodex CLI 0.153.4を固定して同梱依存とし、PCのグローバルCLI設定は変更しません。

モデルは内蔵画像生成の既定を使用します。2026-09-09時点の公式Codex資料はgpt-image-2を記載しています。一方APIにはGPT Image 2.5がありますが、API用モデルを指定することとCodexサブスクで使えることは同じではありません。内蔵ツールは実際の画像モデル識別子を返さないため、生成履歴にはcodex-built-inを記録し、2.5を使用したとは表示しません。

https://learn.chatgpt.com/docs/image-generation
https://developers.openai.com/

実機検証: ChatGPT認証→一時セッション→内蔵画像生成→PNG受信成功。画像生成以外のシェル/MCP/ブラウザ操作は無効。text-onlyの計画・台本サービスとは設定を分離しています。

# 起動と接続

起動のたびに新規作成／既存選択を表示します。前回のプロジェクトは保持しますが、選択前に編集画面・プレビューを起動しません。CLIの現在のプロジェクトは維持されます。

SitesはこのPCの編集エンジンを使用します。ブラウザのローカル接続制限で接続できない場合、エラー画面の「このPCでCuttonを開く」から同じエディター・保存データに直接アクセスできます。これはSitesからの接続制限自体を解除するものではありません。
