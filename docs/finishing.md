# 字幕・背景・BGMの仕上げ

字幕パネルの「字幕の読みやすさを確認」は、語尾だけの字幕、1秒未満の表示、重なり、3行以上、毎秒10文字を超える字幕を一覧にします。診断は文章理解や聞き取り校正の代わりではありません。該当箇所へ移動し、前後との結合や、文字位置での分割を行えます。保存済み字幕を操作し、単語時刻がある場合は保持します。未保存の文章編集は先に保存してください。

- `caption.check {}`: 読み取りのみ。
- `caption.merge {"ids":["前の字幕ID","次の字幕ID"]}`: 連続する字幕を結合。先頭のスタイルとIDを保持します。
- `caption.split {"id":"字幕ID","index":6}`: テキスト欄のUTF-16文字位置で分割。単語時刻がない場合は `at` にタイムライン秒を指定します。
- `caption.look {"ids":["字幕ID"],"preset":"calm"}`: 通常表示。`emphasis` は短い入退場と色による強調です。

グラフィックパネルに背景と構成モーションがあります。

- `background.apply {"preset":"blue"}`: 全尺の背景画像を最下段に追加し、既存映像を1トラック上へ移動。`teal`、`paper` も選択できます。
- `replaceClipId` を指定すると既存の画像クリップを差し替えます。
- `foregroundLane` と `top/bottom/left/right`（%）を指定すると、その映像トラックの余白を透過します。黒帯の検出は自動ではありません。画像自体に含まれる黒はトリミングしない限り残ります。
- `graphics.layout {"preset":"compare","texts":["伝統","現代"],"start":10,"duration":6,"y":18}`: 左右から登場するカード。
- `preset: "steps"` は3項目を順番に表示。各カードは独立して編集可能です。
- グラフィックの位置・長さをフォームで変更すると、既存キーフレームも移動・伸縮します。

ミキサーの「BGMを動画の長さに合わせる」から、取り込み済みの曲を処理できます。

`audio.prepareBgm {"assetId":"曲の素材ID","voiceLane":0,"level":-30,"ducking":true,"fadeIn":2,"fadeOut":4}`

短い曲はクロスフェードを含むループへ加工し、発話の実音声を使って音量を下げます。処理済みWAVを新規素材・空き音声トラックに追加します。元の曲は保持します。生成範囲は先頭から動画末尾まで、最長2時間です。処理後に声の位置・音量・速度を変えた場合は、古いBGMクリップを外して作り直してください。加工されたBGMはライブのサイドチェインではありません。音楽の利用条件・クレジットは配布元に従ってください。

すべて同一のコマンドディスパッチャーを使用するためCLI/MCPからも実行可能です。結合・分割・背景・配置は「戻す」で取り消せます。素材ファイルは削除しません。

書き出しは、通常のベクターグラフィックと字幕を一度の合成で処理し、使用フォントだけを優先的に読み込みます。旧形式のグラフィックが含まれる場合は従来の合成順を保持します。最終解像度と圧縮品質の設定は変更していません。
